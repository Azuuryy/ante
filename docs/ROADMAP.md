# Roadmap

- Foundation: workspace, standalone core, placeholder scene and headless entry point; verify builds and window on supported systems.
- Gameplay core: typed actions and events, seeded dealing, scoring, state transitions, serialization, property tests and documented compatibility fixtures.
- Playable prototype: selection, play/discard, blind targets, progression and a basic shop.
- Optional local resources: research archive formats and permissions before implementing safe bounded import and fallback assets.
- Advanced gameplay and fidelity: effects, jokers, animations, shaders, audio, saves and replay.
- Release: benchmark, profile, validate on Windows and Linux, audit licenses and package.

Each milestone requires tests and honest compatibility documentation. No date or completeness claim is implied.

Before adopting an external engine, complete the outstanding provenance, determinism, effects, scoring and performance checks in [ENGINE_EVALUATION.md](ENGINE_EVALUATION.md).
